# OneSafe design drafts

Sandbox for quick design explorations and interactive prototypes. Everything here is a draft for discussion, not production code or a spec.

## Rules

- **Sample data only.** No customer data, real addresses, balances or credentials. GitHub Pages sites are public.
- **One folder per idea:** `drafts/YYYY-MM-short-name/`
- **Demo stays a demo.** `index.html` is the prototype only. Reasoning and recommendations go in `NOTES.md` next to it.
- **Add new drafts to the list in the root `index.html`** so the team can find them.
